一个温柔的双人小屋：恋爱天数与纪念日、时间线、相册、留言和未来信、心愿、独立心情，以及共同照顾的电子宠物。

## 登录与数据

管理员可以用原来的 ChatGPT 账号进入原站，在「双人小屋设置」中给两位成员分别设置密码。两个人以后选择对应身份、输入密码即可，另一半不需要 ChatGPT 账号。

后端运行于 Sites 的 Cloudflare Workers 环境，使用 D1 保存记录和会话、R2 保存照片。密码使用独立随机盐与 PBKDF2-HMAC-SHA256（600,000 次迭代）哈希；改密码会使对应成员先前的会话失效。

GitHub Pages 运行静态前端，并连接同一个后端；它不能独立运行这里的数据库和服务端路由。跨站访问仅允许 `PAGES_ORIGIN` 指定的完整 HTTPS 来源，照片读取与写入都要验证会话。

## 开发与验证

依赖使用 `package.json` 所指定的 pnpm 版本，Node.js 22.13 或更新版本。

```sh
pnpm install --frozen-lockfile
pnpm run db:generate
pnpm run build
node --test tests/home-domain.test.mjs tests/home-storage.test.mjs tests/home-api.test.mjs
```

`db:generate` 仅在修改数据库结构后运行。已应用的迁移文件不可改写。测试 API 前先构建，API 测试会启动隔离的 Worker、D1 与 R2，不操作线上数据。

Sites 构建与发布使用随项目维护的 `scripts/` 工具与 `.openai/hosting.json`。实际服务端环境变量由托管平台保存：

- `OWNER_LOGIN_EMAIL`：管理员的 ChatGPT 登录邮箱，用于首次设置与密码恢复。
- `PAGES_ORIGIN`：允许的 GitHub Pages 来源（不带路径）。

本地可在未跟踪的 `.dev.vars` 中配置开发值。不要把真实环境变量、数据库或 `.wrangler/` 内容提交到 GitHub。

## 导出 GitHub Pages

```sh
node scripts/export-github-pages.mjs
```

静态文件生成到已忽略的 `outputs/github-pages/`。把其中的文件更新到公开前端仓库的根目录，然后在 GitHub Pages 选择 `main` 分支与 `/(root)`。

GitHub 版默认会话只保存在页面内存；勾选「记住这台设备」后，私人设备会在浏览器本地保存最多 30 天的登录令牌。退出或改密会使会话失效。原站使用 HttpOnly 会话 Cookie。

## 备份、恢复与个人恢复码

完整备份由管理员下载，包含未到期未来信原文、照片数据和宠物状态，不包含密码、会话和恢复码。手机可通过生成后的保存链接或系统分享保存到文件。确认文件已保存后，页面记录本设备的备份日期，并在超过一周或新增较多回忆时提醒。

导入前会展示数量和宠物成长值，并校验新版备份照片的 SHA-256。默认合并文字、心情和照片，保留当前宠物；管理员可输入「恢复小屋」，将文字、设置、心情和宠物恢复到备份。照片始终合并，不删除当前照片。预览后小屋版本变化会阻止恢复，要求重新预览。恢复前建议先下载当前完整备份。

密码可设置为 6 至 128 个字符。在「双人设置 → 密码与恢复码」中，管理员可生成 12 位个人恢复码，界面按每 4 位分组，输入时支持小写、空格或分隔线。原有密码和旧的 64 位恢复码继续有效；重新生成或成功找回密码后换成 12 位新码。

请各自私下保存恢复码；登录页可用它重设密码，无需 ChatGPT 账号。恢复码仅显示一次、使用后轮换、管理员重新设置密码时失效。密码哈希算法、登录会话长度和尝试次数限制不变。正式部署必须应用全部 drizzle 迁移，包括 recovery_codes 表。

相册最多收藏 2,000 张照片，每批可多选 20 张，逐张压缩上传。收藏后仍保留“继续添加照片”入口；中断后可以重试，按照片内容和说明去重，已保存的照片不会因本批其他照片失败而丢失。

宠物在成长值 200、500 时进入少年、成年，两种宠物的头身比例、耳朵和配饰随阶段变化。喂食、玩耍、摸摸、睡眠和双人陪伴各有对应动作，睡眠期间实时显示倒计时与精力恢复。照顾偏好由共享日记计算；双人小游戏需两位成员在 5 分钟内先后回应才增加成长值，操作仍使用服务器去重和冷却。

布置宠物小窝时，颜色和六种装饰直接在主场景、宠物小窝和编辑预览里更新。取消恢复已保存的布置，保存后同步给另一位成员。装饰仍按成长值解锁，不扣成长值。

## 双人日常扩展

此工作副本新增双人每日问题（双方回答后揭晓）、约会灵感罐（随机抽取与回忆关联）、双人日历与见面倒计时、专属小券、宠物小窝、个人偏好档案、离线月度回忆册。扩展数据保存在原 room_state JSON 中，无须新增数据库表；已有小屋会在读取或操作时补齐默认值。

问答答案在服务器端按登录身份过滤；完整备份包含未揭晓答案，下载前会明确提示管理员。月度回忆册不收入未揭晓问答或信件。照片按上传月份整理，旧心愿没有完成时间时不计入，宠物日记限当前保留记录。

可运行 `node scripts/build-review.mjs` 生成单文件演示预览 `outputs/review/couple-home-next-preview.html`。仅使用虚构数据，支持切换演示身份；刷新重置，不连接生产服务。使用 drizzle-kit 已有的 esbuild 依赖打包。已完成审阅后的修正：支持往日补答、全部灵感管理，导入限制个人答案与档案，恢复后重新关联故事记录。
